How Zero-Knowledge k-Anonymity Works

[+] Expand
1. Client SHA-1 Hashing

Password string is converted into a 40-character SHA-1 hash on your system.

2. 5-Char Prefix Query

Only the first 5 hex characters (e.g. 5BAA6) are sent to the API.

3. Local Suffix Match

The API returns hundreds of suffix hashes matching the prefix. Match comparison occurs in memory.

Because thousands of passwords share the exact same 5-character SHA-1 prefix, neither KeyGuard nor HaveIBeenPwned can reconstruct your original password from the prefix alone.
